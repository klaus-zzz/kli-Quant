# Agent 工作台设计预览

通过现有前端开发服务访问 `/demo/`。这是独立设计稿，不接入业务 API，不读取聊天凭据，不改变现有主页面。

默认进入通用对话首页，包含整理会议记录、理解接口代码、事件研究三类任务示例。左侧组织对话与任务；右侧按需查看资料、产物和过程，研究任务另外提供来源引用及固定版本。所有内容都是设计示例，不表示已接入对应后端能力；输入只保留在当前页面，刷新后重置。

设计采用浅灰导航、白色阅读区和可折叠资料栏。桌面按需并排查看对话与任务详情，窄屏导航使用带轻遮罩的滑入抽屉，支持点空白处、Escape 或选择会话关闭，并遵循系统的减少动态效果设置。资料在桌面按需并排展开，在窄屏以留边的详情面板滑入，支持遮罩关闭；没有任务资料时隐藏标签栏。

输入区只保留统一任务入口；右侧“思考链”弹层参考用户提供的 Codex 控件截图，仅展示居中的当前档位、说明和滑杆，拖动时连续跟手，松开后以短过渡吸附到最近档位；方向键逐档调整，并遵循系统的减少动态效果设置。低、中、高、极高是演示档位，不切换研究流程、不选择模型、不发送真实参数；正式接入时需按模型支持的档位映射。

## 参考与字体

- [Claude Research 官方介绍](https://claude.com/resources/articles/research)：参考可展开的研究过程与正文引用。
- [ChatGPT deep research 官方介绍](https://openai.com/index/introducing-deep-research/)：参考对话中的研究报告及步骤、来源侧栏。
- [Manus Wide Research 官方介绍](https://www.manus.im/blog/introducing-wide-research)：参考以任务为中心的研究组织；没有接入或复制其执行能力。
- [Geist 官方仓库](https://github.com/vercel/geist-font)：本地字体用于西文字体和数字，按 SIL Open Font License 使用，许可证保留在 `assets/OFL.txt`。中文使用系统无衬线字体。

这些产品仅作为交互参考，没有复制其品牌资产或源码。官方参考截图不随 Demo 分发。
