# 界面与交互

先读 [前端工程规则](../AGENTS.md)。

- 配置状态与实际连接成功分开显示；未实现功能必须明确标注。
- 研究界面区分事实、条件性判断、待验证假设和计算结果。
- 引用指向固定证据版本及原文位置；更新时间不得替换最初发布时间。
- 研究完成不能直接显示为投资机会成立，撤回和失败历史不能隐藏。
- 处理加载、空结果、部分结果、失败及取消状态，不用成功占位数据掩盖故障。
- 请求卸载时取消或忽略过期响应；不能以局部失败覆盖无关的成功状态。
- 使用语义化元素、明确的文字状态及响应式布局，不能只靠颜色表达结论。
- 浏览器展示外部材料时按不可信内容处理，不直接插入未清理 HTML。
- 沿用两空格缩进和简短中文职责注释；API 变化同步后端与针对性验证。
