# 应用接入与客户端

先读 [根目录规则](../../AGENTS.md)。

## 模块索引

| 修改范围 | 职责与规则 |
| --- | --- |
| `application.py` | 通过 `fina_agent.applications` 入口点注册工具、契约和校验器 |
| `config.py` | 扩展后端配置，读取金融数据凭据 |
| `cli.py` | 通过 HTTP 提交研究、创建复核执行和查询状态 |
| `finance/` | [金融规则](finance/AGENTS.md)：业务契约、行情与计算校验 |

## 接入约束

- 通用 API、Worker、执行存储与沙箱由 Fina-Agent 提供；本包在独立金融服务中运行领域扩展，底座服务不安装本包。
- 应用注册和 CLI 入口维护在 pyproject.toml；内部模块调整时同步调用方和测试。
- `application.py` 负责组装，金融计算和判断规则放在 `finance/`。
- 金融校验规则变更必须升级应用版本，并同步包版本及对应测试；纯目录调整不改变版本。
- CLI 保持 HTTP 客户端职责，不直接访问数据库、行情供应商或沙箱。
- 配置对象仅用于后端，不传入模型上下文、客户端响应或日志。
- 接入底座新契约时同步调用端与测试，不在本仓库复制底座实现或实例提示配置。
