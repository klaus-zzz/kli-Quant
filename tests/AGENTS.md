# 测试

先读 [根目录规则](../AGENTS.md)。

## 目录与职责

| 范围 | 规则与职责 |
| --- | --- |
| `conftest.py` | 共享金融实例配置、内存归档及 SQLite 夹具 |
| `unit/` | 遵循本文件；应用注册、行情边界、计算与结论校验的离线回归 |
| `integration/` | [集成规则](integration/AGENTS.md)：真实服务、研究与持续对话联调 |

- 从仓库根目录执行 `uv run pytest -m 'not integration'`；定向离线测试可指定 `tests/unit/`。
- 离线用例使用虚构记录与凭据，不调用真实模型、数据源、对象存储或沙箱。
- 共享夹具保留在本层，使单元与集成测试均可发现；底座配置路径以本文件所在测试根目录为基准。
- SQLite 只用于单元测试，不能据此宣称 PostgreSQL 锁、迁移或并发行为已验证。
- 重构前后检查测试收集数量和结果，避免移动目录后漏收集或失去夹具。
- 金融回归重点覆盖时间边界、缺失值、引用归属、收益重算与证据不足；缺陷先写失败用例再修复。
